### 🌡️ Hybrid Edge–Cloud IoT Industrial Safety Framework

**Final-Year Project**

An IoT-based industrial safety monitoring system designed to combine edge devices with cloud-connected monitoring and emergency response.

**Planned / implemented technology stack:**
- Hardware: ESP32 and environmental sensors
- Messaging: MQTT with Mosquitto
- Backend: Node.js and Express
- Database: PostgreSQL
- Deployment: Docker Compose
- Monitoring: Grafana
- Frontend: React

The project aims to support real-time hazard monitoring and autonomous emergency response. Hardware integration and end-to-end functionality are being developed in stages.
